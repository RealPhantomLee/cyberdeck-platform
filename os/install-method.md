# 💽 OS Install Method  
Brick 2 — Cyberdeck

This document describes how the operating system is installed on the Brick 2 cyberdeck.

The goal is clarity and repeatability—not exhaustiveness.

---

## Supported Installation Approaches

Brick 2 supports **two valid OS installation methods**.

Both are acceptable. Only one is required.

---

### Option A — Clone from Brick 1 (Preferred)

The cyberdeck OS is cloned directly from the finalized environment created in **Brick 1**.

**Why this is preferred**
- Maintains consistency across bricks
- Preserves hardening and configuration
- Reduces setup time
- Ensures predictable behavior

This method treats Brick 1 as the **gold image**.
