# 🧾 Bill of Materials  
Brick 2 — Cyberdeck

This document lists the hardware components used or planned for the Brick 2 cyberdeck.

It focuses on **what exists**, not where to buy it or how to assemble it.

---

## Core Components (Required)

| Component | Description | Notes |
|--------|------------|------|
| Raspberry Pi | Pi 4 or Pi 5 | Pi 5 preferred for NVMe support |
| Storage | microSD card | OS boot medium |
| Power Source | Battery bank or internal battery | Must support stable 5V output |
| Case / Enclosure | Protective or custom | See `enclosure-notes.md` |
| Input Device | Keyboard / controller | Compact, wired or wireless |
| Display | HDMI screen or none | Headless operation supported |

---

## Storage Expansion (Optional)

| Component | Description | Notes |
|--------|------------|------|
| USB SSD | External storage | For tools, logs, captures |
| NVMe SSD | Pi 5 only | Requires compatible HAT |

---

## Networking (Optional / Future)

| Component | Description | Notes |
|--------|------------|------|
| External Wi-Fi Adapter | Monitor-mode capable | Internal Wi-Fi is insufficient |
| Ethernet Adapter | USB or onboard | Useful for labs |

---

## Interface & Feedback (Optional)

| Component | Description | Notes |
|--------|------------|------|
| OLED Display | Status output | Non-essential, cosmetic |
| Camera Module | Pi camera | Optional |
| Speaker / Mic | Audio I/O | Optional |
